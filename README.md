# Exercícios de CSS Position – HTML e CSS

Este repositório contém a resolução de **10 exercícios práticos de CSS Position**, desenvolvidos com HTML e CSS para aprimorar os conhecimentos sobre posicionamento de elementos em páginas web. A atividade tem como objetivo reforçar o aprendizado por meio da prática, explorando diferentes comportamentos de posicionamento e suas aplicações.

O projeto foi desenvolvido para fins educacionais e de treinamento, como parte da prática de desenvolvimento web.

## Conteúdo do Repositório

- **`index.html`:** Arquivo HTML utilizado para estruturar os elementos dos exercícios.
- **`style.css`:** Arquivo CSS com as soluções dos 10 problemas, organizadas e comentadas.
- **PDF dos exercícios:** Documento contendo os enunciados dos problemas propostos para resolução.

## Conceitos Praticados

- **`position: static`:** Posicionamento padrão dos elementos.
- **`position: relative`:** Posicionamento relativo à posição original do elemento.
- **`position: absolute`:** Posicionamento em relação ao elemento ancestral de referência.
- **`position: fixed`:** Posicionamento fixo em relação à janela de visualização.
- **`position: sticky`:** Posicionamento que acompanha a rolagem dentro de determinados limites.
- **Propriedades de posicionamento:** Utilização de `top`, `right`, `bottom` e `left`.
- **Hierarquia de elementos:** Prática da relação entre elementos pais e filhos.
- **`z-index`:** Controle da sobreposição e da ordem de exibição dos elementos.

## Como Executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `style.css`.
4. Escolha a questão que deseja visualizar e descomente o bloco de código correspondente.
5. Caso necessário, descomente também a estrutura HTML relacionada à questão no arquivo `index.html`.
6. Salve os arquivos e abra o `index.html` em um navegador para visualizar a resolução.

**Importante:** Os códigos estão comentados e organizados por questão. Para testar cada solução, basta descomentar o trecho correspondente nos arquivos HTML e CSS. Verifique se apenas a questão desejada está ativa para evitar conflitos entre os exercícios.

## Objetivo do Projeto

Consolidar os conhecimentos sobre a propriedade `position` do CSS por meio da resolução de 10 problemas práticos, desenvolvendo maior familiaridade com o posicionamento, a organização e a sobreposição de elementos em páginas web.

## Aprendizados

Durante a atividade, foram praticados diferentes tipos de posicionamento, o comportamento dos elementos em relação aos seus ancestrais, o uso de coordenadas CSS e o controle da sobreposição de elementos.

## Tecnologias Utilizadas

- **HTML5:** Estruturação dos elementos utilizados nos exercícios.
- **CSS3:** Aplicação das propriedades de posicionamento e estilização.
